# Personal CV Website

这是一个适合 GitHub Pages 发布的个人简历 / 作品集网站模板。

## 目录说明

- `index.html`：页面结构
- `styles.css`：页面样式
- `script.js`：页面脚本

## 需要替换的内容

请先把页面中的占位文本改成你的真实信息：

- 你的名字
- 职位 / 头衔
- 个人简介
- 工作经历
- 项目经验
- 教育背景
- 联系方式（GitHub、LinkedIn、Email）

## GitHub Pages 发布步骤

1. 创建一个 GitHub 仓库
2. 把这个目录中的内容上传到仓库
3. 进入仓库设置 -> Pages
4. 选择部署源：`Deploy from a branch`
5. 分支选择 `main`，文件夹选择 `/root`
6. 等待 GitHub 生成页面
7. 访问 `https://<你的用户名>.github.io/<仓库名>/`

## 本地预览

在项目目录中运行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```
